Standalone Managed Service Account

Aliases: sMSA
Categories: Active Directory / Service Identity

Overview

A Standalone Managed Service Account (sMSA) is a type of Service Account managed through Active Directory.

Microsoft describes an sMSA as a managed domain account intended for services on a single computer.

Password Management

Windows can automatically maintain the account password for an sMSA.

This reduces the need to manually rotate long-lived credentials when compared with a conventional User Account used as a service identity.

SPN Management

sMSAs also simplify management of Service Principal Names (SPNs).

SPNs are important for identifying service identities during Kerberos authentication.

Single-Computer Scope

An sMSA is designed for service use associated with one Computer Account.

For a common service identity used across multiple servers, Windows Server provides the Group Managed Service Account (gMSA).

Security Position

sMSAs reduce manual service-credential administration and make it easier to isolate service identities.

Their single-computer scope is a major distinction from gMSAs.
