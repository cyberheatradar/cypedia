Key Distribution Center

Aliases: KDC
Categories: Kerberos

Overview

Primary source: RFC 4120 - The Kerberos Network Authentication Service (V5)

The Key Distribution Center (KDC) is the central trusted service in Kerberos.

A KDC supplies tickets and temporary Session Keys and supports authentication of principals registered in a Realm.

AS and TGS

A KDC logically provides two services:

  • Authentication Server (AS);
  • Ticket-Granting Server (TGS).

The AS performs initial authentication and issues a Ticket-Granting Ticket (TGT).

The TGS accepts a valid TGT and can issue a Service Ticket for a target service.

Account Database

The KDC requires access to information about principals in its Realm and to the long-term keys required by the protocol.

The KDC is therefore a highly trusted component of a Kerberos Realm.

Session Keys

The KDC creates and distributes temporary Session Keys for Kerberos exchanges.

Different Session Keys are used between the client and TGS and between the client and application services.

Active Directory

Primary source: Microsoft - Key Distribution Center

In Active Directory, the KDC is implemented as a domain service on a Domain Controller.

It uses Active Directory as its account database.

Microsoft also documents use of the Global Catalog for referrals to KDCs in other Domains.

Availability

Multiple Domain Controllers can handle KDC requests in an AD DS Domain.

This provides availability for authentication and ticket-granting operations.

Security Significance

A KDC participates in management of principal key information and ticket issuance.

Compromise of the KDC or critical KDC key material can undermine authentication trust throughout the Realm.

In Active Directory, KRBTGT key material is especially important to TGT security.
