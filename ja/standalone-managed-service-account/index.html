Standalone Managed Service Account

別名: sMSA
カテゴリ: Active Directory / Service Identity

概要

Standalone Managed Service Account（sMSA）は、Active Directoryで管理されるService Accountの一種です。

MicrosoftはsMSAを、単一computer上のserviceで利用するmanaged domain accountとして説明しています。

Password Management

sMSAではWindowsがaccount passwordを自動的に管理できます。

通常のUser Accountをservice identityとして利用する場合に必要となるmanual password rotationの負担を減らせます。

SPN Management

sMSAはService Principal Name（SPN）管理を簡素化するための仕組みも提供します。

SPNはKerberosでservice identityを識別する重要な情報です。

Single-Computer Scope

sMSAは基本的に1台のComputer Accountに対応するservice用途を想定しています。

複数serverで同じservice identityを共有する用途にはGroup Managed Service Account（gMSA）が用意されています。

Security Position

sMSAはservice credentialをadministratorが長期間手動管理する必要を減らし、serviceごとのidentity分離を行いやすくします。

ただし利用可能なcomputer scopeが単一computerであることは、gMSAとの重要な違いです。
