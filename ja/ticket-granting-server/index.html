Ticket-Granting Server

別名: TGS
カテゴリ: Kerberos

概要

主な出典: RFC 4120 - Client/Server Authentication Exchange

Ticket-Granting Server（TGS）はKey Distribution Center（KDC）を構成するserviceの1つです。

TGSは有効なTicket-Granting Ticket（TGT）を持つKerberos clientからrequestを受け、target service用のService Ticketを発行します。

TGS-REQ

clientはTGSへTGS-REQを送信します。

requestにはTGT、Authenticator、target serviceを識別するinformationなどが含まれます。

Active Directoryではtarget serviceの識別にService Principal Name（SPN）が重要です。

TGTの検証

TGSはTGTを処理し、client/TGS間のSession Keyを利用してAuthenticatorなどを検証します。

requestが有効であればtarget service向けのcredentialを生成します。

TGS-REP

TGS-REPにはtarget service用のService Ticketとclientが利用するservice session keyに関するinformationが含まれます。

Service Ticketはtarget service側が利用できるlong-term keyで保護されます。

Active Directory

AD DSではserviceのSPNは通常、computer accountやService Accountなどのaccountへ登録されます。

そのaccountに関連するkey materialがService Ticketの保護に関係します。

Windows KerberosではService TicketへPACが含まれる場合があります。

Kerberoasting

Kerberoastingでは、正当なTGTを持つ主体がTGSへService Ticketを要求できるKerberosの通常機能が利用されます。

弱いService Account passwordやlegacy encryptionなどが存在する場合、取得したticket dataがoffline password guessingの対象になることがあります。

Silver Ticket

Silver Ticketはservice側のkey materialを利用してService Ticketを偽造するattack techniqueです。

これはGolden TicketがTGTを対象とする点とは異なります。
